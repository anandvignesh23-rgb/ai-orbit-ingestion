What This System Does

A compact backend pipeline focused on reliable, structured AI ecosystem data.

API-First Ingestion

Collects structured ecosystem data from APIs, feeds, and trusted official sources instead of brute-force scraping.

Common Schema

Transforms source-specific responses into one consistent AI Orbit entity model.

Entity Resolution

Combines canonical URLs, normalized names, RapidFuzz similarity, entity type, and metadata signals.

Knowledge Relationships

Maps connections such as companies developing models, tools solving tasks, and MCP servers integrating with tools.

Validation

Checks schema integrity, duplicate candidates, relationship references, and dataset coverage before export.

Public Data API

Exposes entities, relationships, statistics, health status, and search through FastAPI endpoints.
